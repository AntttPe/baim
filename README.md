# Cross-Site Scripting (XSS)

Repozytorium zawiera materiały praktyczne do wykładu o podatności Cross-Site Scripting (XSS). Celem warsztatów jest zrozumienie, jak działa ten atak w praktyce oraz jak się przed nim chronić.

##  Jak korzystać z repozytorium?
Nie musisz niczego instalować. Wystarczy sklonować to repozytorium lub pobrać je jako plik ZIP, a następnie otwierać pliki `.html` bezpośrednio w swojej przeglądarce.

## Zadania
Przygotowaliśmy dwa scenariusze testowe, bezpośrednio nawiązujące do przypadków z wykładu.

1. **[Zadanie 1: Reflected XSS](./Zadanie_1_Reflected/README.md)** - Zobaczysz, jak niebezpieczne może być bezpośrednie odbijanie parametrów z adresu URL.
2. **[Zadanie 2: DOM-based XSS](./Zadanie_2_DOM/README.md)** - Przeanalizujesz, w jaki sposób błędy w kodzie JavaScript po stronie klienta (frontend) prowadzą do wykonania złośliwego kodu.
